# Лабораторная работа № 10

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Функции с параметрами и результатом

## Назначение файлов проекта

* **`main.c`** — вычисление максимума трёх целых чисел с помощью вспомогательной функции `max2(a, b)`.
* **`self.c`** — вычисление разности между максимумом и минимумом трёх чисел с помощью функций `min2(a, b)`, `max2(a, b)` и `range3(x, y, z)`.
* **`tests.txt`** — протокол обязательных и собственных граничных тестов с ожидаемыми и фактическими результатами.

## Ограничения входа

* Вводятся три отдельных целых числа типа `int` в диапазоне от `-1000` до `1000` включительно.
* При нечисловом вводе выводится `Input error`, при выходе за пределы диапазона — `Range error`.

## Команды сборки (PowerShell / Bash)

```bash
gcc -std=c11 -Wall -Wextra -Wpedantic main.c -o lab10
gcc -std=c11 -Wall -Wextra -Wpedantic self.c -o self
```

## Пример работы

### Основная программа (`main.c`)
Ввод: `4 -2 7` -> Вывод: `Max = 7`

### Самостоятельная работа (`self.c`)
Ввод: `4 -2 7` -> Вывод: `Range = 9`
